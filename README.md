Rick Rolls (food/recipe app)
---

- Presents a user-friendly (though ugly) interface for searching up recipes, as well as adding some fun facts and a random recipe you could try on your main screen 
- Gives information about the selected meal, the steps in making it, as well as the ability to add it to a list of favorite meals which are stored locally in RoomDB
- The search bar supports a search by name an ingredients of the dish. It enables autocomplete to help you with searching a recipe
